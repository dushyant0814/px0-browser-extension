What the command does

  • Downloads px0-extension-host for your platform from the GitHub release and checks it against the release checksums.
  • Installs px0 from px0.ai if it is not already installed.
  • Allows only this extension to talk to the helper.

Supports macOS and Linux with Chrome, Chromium, Brave, Edge and Arc. Read the script before running it if you like.
